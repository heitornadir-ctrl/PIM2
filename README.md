# 📚 Sistema Acadêmico Integrado com Apoio de IA
O Sistema Acadêmico Integrado com Apoio de IA é um projeto de software desenvolvido com o objetivo de otimizar o gerenciamento de usuários (coordenadores, professores e alunos) e de notas e atividades em uma instituição de ensino superior.
Inicialmente, o sistema está configurado para fazer referência ao curso de Análise e Desenvolvimento de Sistemas de uma universidade. Este projeto foi concebido e construído para o Projeto Integrado Multidisciplinar (PIM) do 2º Semestre na UNIP SJC-Dutra.

#✨ Funcionalidades Principais
O programa visa centralizar e simplificar o gerenciamento dos seguintes aspectos:
*Gerenciamento de Usuários: Cadastro e controle de acesso para Coordenadores, Professores e Alunos.
*Gerenciamento de Notas: Registro e manutenção de notas e avaliações.
*Controle de Atividades: Organização e acompanhamento de tarefas e atividades acadêmicas.

# 💻 Estrutura do Projeto
O projeto é composto por código em múltiplas linguagens (C e Python) e inclui diagramas UML estruturados no Asta e documentação escrita em Word.doc.

# 📂 Arquivos Principais
| Arquivo | Linguagem / Tipo | Descrição |
| `IA_Oficial.py` | Python | Módulo de Inteligência Artificial ou script principal em Python. |
| `InterfaceSistemaAcademico.pyw` | Python (sem console) | Arquivo executável da interface gráfica do usuário (GUI). |
| `ProgramaFinal.c` | C | O código-fonte final da versão em C do sistema. |
| `sistemaAcademico_unificado.h` | C Header | Arquivo de cabeçalho (header) em C para definições e protótipos de funções. |
